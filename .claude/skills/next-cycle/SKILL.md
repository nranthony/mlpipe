Read goals/STATUS.md to find the current cycle. Read that cycle's goal file, DESIGN.md
sections it references, and AGENTS.md. Check work/ for open items blocking the cycle
(e.g. environment asks) before starting. Plan the implementation, list the acceptance
tests you will write first, then execute. When acceptance passes, update STATUS.md
with a work-log entry and stop for review. Do not start the next cycle.
